## `06 /` System architecture

An illustrative workflow: I choose the tools, carry context between steps, and decide what goes into the repository. Tool roles vary by task.

```text
Human / intent + decisions
  |
  v
Planning
  ChatGPT / Claude Code / Codex
  |
  v
Implementation
  Claude Code / Codex / Copilot
  |
  v
Review
  Human + tests + AI feedback
  |
  v
Git repository
  |
  v
Software
  |
  +--> feedback --> Human
```

Manual handoffs, human judgment. The orchestration layer is mostly me switching tabs.
